# Beam Designer

A Python desktop app for analyzing simply supported and cantilever beams with
point and uniform loads. It displays shear, moment, and deflection diagrams,
checks bending and deflection, and supports saving designs plus CSV and PDF
exports.

## Install

From the `beam_desktop` folder, install the required packages:

```bash
python -m pip install numpy matplotlib
```

## Run

From the `beam_desktop` folder, start the app with:

```bash
python app.py
```
